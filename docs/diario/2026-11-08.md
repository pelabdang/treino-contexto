## Decisões
- **Angelo, `carga@2` (#255):** no hrTSS, se há voltas, nenhuma tem FC e a atividade tem FC média, a atividade entra como volta única
  (`granularidade = 'atividade'` quando o hrTSS vence). FC em parte das voltas segue a cobertura de 95%. Limitação: a volta única
  subestima a carga de treinos variáveis. Adendo de 08/11 na [[decisoes/0010-carga-de-treino]].
- **Theo, API da carga (#142):** `GET /atletas/{id}/carga` devolve a série sem arredondar (a tela decide as casas; proposta de 1) e o
  objeto `carga` da atividade; `pendente` para atividade elegível sem linha ou com versão antiga; a API nunca devolve limiar, zonas,
  recordes nem a carga do Garmin. A conversão para o contrato fica no serviço.
- **Theo, conferência (#144):** o comando só lê o banco, sem rede; o terminal mostra só contagens; duas regras de dias, a da ADR
  (descarta dia com atividade sem carga) e a leitura complementar (todos os dias).
